=== Accessibility Statement ===

Twenty Twenty-Four was tested by the WordPress Accessibility Team during the development process, using common accessibility testing tools including screen readers. All WordPress core themes go through a similar testing process, with the goal of meeting WCAG 2 guidelines at level AA, in keeping with the WordPress accessibility standards.

== Testing Tools and Methodology ==

Accessibility was considered as a primary goal from the initial design phase through final release. Accessibility testing was performed at various intermediate stages of the development process.

During development, tools used included the WAVE toolbar, manual testing using a keyboard and a screen reader, and manual color contrast tests.
